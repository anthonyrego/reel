# reel: notes for coding agents

reel records the screen on macOS — a whole display, one window or a drag-selected area — with system audio and a chosen microphone mixed into **one** audio track, and saves an MP4 that it copies to the clipboard as a file (paste into Slack). A regular Dock app: a main window to set up and list recordings, a small floating control while recording, pause/resume, and trim after stop.

It's Go on SDL3 (`github.com/Zyko0/go-sdl3`, purego, no cgo) with our own renderer, copied from an earlier project of the author's; the per-file provenance lines say which files. The recording pipeline calls ScreenCaptureKit, AVFoundation and CoreMedia through `purego/objc` in `internal/mac`.

- **What the probe found (`probe -self`, 2026-10-13):** a stream delivers on our queue, and its `synchronizationClock` is the host clock (−0.007 ms). Screen frames come at the FPS cap while the content changes, `420v`, and the first one was `complete` (no `started` seen with a window filter: the writer must accept both). System audio is 48 kHz stereo float32 planar in 960-frame (20 ms) buffers, and keeps coming while nothing plays (zeros: 50 buffers a second after the speakers closed), at 47 999.9 Hz with no PTS gaps; it arrives a median 61 ms after its PTS (max 80 ms), so the mixer needs a jitter window over 100 ms. **A covered window isn't drawn, so its capture is all `idle` frames with no pixels**: the beacon keeps itself on top, and recording a covered window of another app may freeze the same way. `CMSampleBufferGetAudioBufferListWithRetainedBlockBuffer` wants the list's exact size (a bigger one fails with −12737).

## Packages
| Package | What it does |
|---|---|
| `internal/mac` | The macOS bridge (purego/objc, never SDL): permissions (`ScreenAccess`, `MicAccess`, the requests), `Mics` (AVCaptureDevice: uniqueID = ScreenCaptureKit's `microphoneCaptureDeviceID`, transport), `ShareableContent` (displays with their pixel scale, other apps' windows), `Cameras` (iPhones only in Reel.app, whose Info.plist asks for them), `CameraAccess`, `OnActive`/`AppActive` (reel in front), `OptionHeld` (⌥, whichever app is in front). `StartCamera`: a camera's BGRA frames (`Sample.Pixels`) to a handler on a queue of its own through a runtime class `ReelCameraOutput`; it refuses outside Reel.app (`InBundle`: a process without `NSCameraUsageDescription` is killed when it opens one) and without the permission (opening an unasked camera prompts). `StartStream`: one SCStream with the screen, system audio and a mic (`Target.Show`: reel windows a display recording shows anyway), delivered as `Sample`s (PTS, frame status, pixel buffer, audio format, PCM) to a handler on our serial queue (autorelease per sample) through a runtime class `ReelStreamOutput`; ScreenCaptureKit's protocols have no runtime objects until something refers to them, so `protocol` registers them. `Writer`: AVAssetWriter behind a state machine (H.264 settings checked with canApplyOutputSettings, appends only while writing, the hot path's messages pre-registered). `Trim`: part of an MP4 copied without re-encoding (AVAssetExportSession passthrough, its output type checked before it's set). `Frames`: a recording's pictures one at a time, exactly the frame shown (AVAssetImageGenerator; the handler's CMTime arrives as a pointer), checked against `testdata/clip.mp4`. `Player`: AVPlayer and an AVPlayerItemVideoOutput (BGRA at a size asked for, made again for a new one): play, pause, seek (exact, or loose while dragging; only once ready, never with a handler), mute, and the frame for a host time when it's new; its per-frame messages pre-registered. ## Rules
- **Don't open the user's microphone from an agent.** Anything that records with a mic is the user's to run. Agents list devices (`devices` opens nothing and asks nothing) and use `selftest`'s fake mic, which goes through the same path a real one does.
- **Don't open the user's camera from an agent.** Only Reel.app can (`StartCamera` refuses in the bare binary, and without the permission); agents use the fake camera (`app -fake-camera`, `selftest -camera`, `render -scene bubble`), which goes through the same path from the cut on. `devices` lists cameras without opening one.
- **Don't capture the user's screen from an agent.** Self-tests record only reel's own windows (`-camera`: the beacon and the bubble, through a display filter of reel's app only). Don't print other apps' window titles into a transcript: `devices` lists them, so filter its output when an agent runs it.
- **Don't trigger permission prompts from an agent.** The requests only run from the app's buttons.
- **Never touch the user's real data.** Dev runs set `REEL_DATA_DIR` to `.dev/data` (the Makefile does, and `make run` passes it through `open --env`). Recordings go to `<data>/recordings`, not `~/Movies/Reel`. `reel` with no subcommand opens the app on the real paths, so never run it bare.
- **Run the app as the signed bundle (`make run`).** macOS gives permissions to the process that's responsible: a binary started from a terminal records with the terminal's permissions, and only `open` makes Reel.app its own. Dev bundles are signed with the user's Apple Development certificate (`SIGN`, its SHA-1) so permissions are kept against "identifier + certificate leaf" and survive rebuilds; `codesign -d -r- build/Reel.app` must show `certificate leaf`, never a `cdhash`. No hardened runtime in dev.
- **Objective-C exceptions kill the process.** purego can't catch them. Every selector, symbol, constant and protocol `internal/mac` uses goes in its tables (checked by `mac_test.go`); framework constants are read through `Dlsym`, never hard-coded; framework objects are kept in states where they can't throw (AVAssetWriter behind a state machine from M2).
- **Keep Go off real-time threads.** ScreenCaptureKit's sample handlers run on a dispatch queue we create, not an audio IO thread; they only classify and hand off. No AudioUnit render callbacks.
- **The core stays pure.** `internal/deps/purity_test.go` has two tiers: the pure packages import neither SDL nor purego nor `internal/mac`; `internal/mac` never imports SDL. Add new packages to its lists.
- **Only the main thread touches the GPU.** Other goroutines hand work over (a mutex-guarded value) and call `platform.Wake()`.
- **Running the app from an agent** opens a real window on the user's screen: keep runs short (`-exit-after`, stdio redirected: `</dev/null >/dev/null 2>&1`), run the bare `build/reel app` (it uses the terminal's permissions and asks nothing unless a button is clicked) and check nothing is left running. Prefer offscreen renders.
- **Graphics shaders use no storage buffers.** After editing `shaders/src`, run `make shaders` and commit the outputs and `manifest.json`.
- **Colors come from `theme.Palette`.** Sizes are logical units.
- **Exit checks are run, not asserted.** Look at what you built: render it and read the PNG; from M2, ffprobe what was recorded.
- **Copied code** keeps its one-line provenance comment.

## Commands
```
make build          # build/reel
make check          # vet + test + shader manifest + build
make app            # the signed build/Reel.app
make run            # make app, then open it (user only: it can ask for permissions)
make render         # offscreen PNG of the home scene -> build/render.png (ARGS="-state hover-card", "-width 640", "-live", "-state camera-menu", "-scene trim -state replace", "-scene trim -file X.mp4", "-scene player -state scrub" (also paused, muted, loading, error, copy-error; -file X.mp4 takes the frame through mac.Player), "-state hover-play", "-scene icons", "-scene bubble -state off", "-scene bubble -state hover" (also option, square, framed))
./build/reel devices [-all]   # permissions, mics, cameras, displays, windows (opens nothing, asks nothing)
REEL_DATA_DIR=$PWD/.dev/data ./build/reel probe -self -for 6s </dev/null   # agents: records only its own flashing, clicking window (kept on top) and reports what arrives
./build/reel probe -display main -mic default -for 10s   # user only: a display and a mic (also -window ID, -app Chrome, -system-audio=false)
REEL_DATA_DIR=$PWD/.dev/data ./build/reel selftest -for 20s </dev/null   # agents: the beacon + a fake mic to an MP4, then every check (ffmpeg for codec, frames, audio); -video-only, -fake-mic=false, -mic-ppm N
REEL_DATA_DIR=$PWD/.dev/data ./build/reel selftest -for 20s -pause-at 4s -pause-for 3s -fake-mic=false -fps 60 </dev/null   # agents: the pause checks
REEL_DATA_DIR=$PWD/.dev/data ./build/reel selftest -for 12s -interrupt-at 5s -fake-mic=false </dev/null   # agents: a stream ending by itself (also -hide-at/-show-at, -minimize)
REEL_DATA_DIR=$PWD/.dev/data ./build/reel selftest -for 8s -trim-from 2s -trim-to 5s </dev/null   # agents: M6's gate, a trim of the recording checked against it
REEL_DATA_DIR=$PWD/.dev/data ./build/reel selftest -for 12s -camera </dev/null   # agents: M8's gate, the bubble beside the beacon with the fake camera (also -mic-delay 100ms without -camera)
./build/reel trim -from 2s -to 5s [-out PATH] FILE.mp4   # a copy without re-encoding, "… trimmed.mp4" beside FILE (agents: only on files under .dev)
./build/reel record -display main -mic default [-for 60s]   # user only: a real recording to <recordings> (Ctrl-C stops; also -window ID, -app NAME, -system-audio=false)
./build/reel micsync -mic <ID>   # user only: clicks through the speakers (a small window flashes with each); how late the mic hears them against the tap. -mic none: the tap alone (agents)
./build/reel analyze [-flash-period 500ms] FILE.mp4   # dev: the same checks on any recording
REEL_DATA_DIR=$PWD/.dev/data ./build/reel app -exit-after 4s </dev/null >/dev/null 2>&1   # a short window run from an agent (-trim FILE: open on the trim screen; -play FILE -muted: on the player screen, playing without sound, its stats in app.log at the end; -fake-camera: the bubble with the fake camera, as if reel were in front)
codesign -d -r- build/Reel.app   # must say certificate leaf
```
Logs: `.dev/data/logs/<subcommand>.log`.

## Conventions
- **Commits:** conventional style (`feat(mac): …`), one per logical step. Push only when the user says. The repo is public (github.com/anthonyrego/reel, MIT): keep personal details (names, emails, machines, certificates) out of files and commits; `SIGN` lives in the git-ignored `local.mk`.
